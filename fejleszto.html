Fejlesztői és Verziókezelési (DevOps) Kézikönyv

1. Verziókezelési Stratégia (Git Workflow)

A projekt verziókezelése Git alapokon, a GitHub platformon történik. Mivel az alkalmazáson jelenleg egyetlen fejlesztő dolgozik, egy egyszerűsített, Trunk-based fejlesztési modellt alkalmazunk.

  • Fő ág (Branch): Kizárólag a main ágon történik az integráció.
  • Eszközök: Lokálisan a macOS környezeten futó GitHub Desktop kliens biztosítja a grafikus felületű, hiba-mentes commitolást.
  • Commit Konvenciók: A commit üzenetek magyar nyelvűek, rövidek és leíró jellegűek, amelyek az elvégzett konkrét javításra vagy új funkcióra fókuszálnak (pl. "Verziószám hozzáadása a lábléchez").

2. CI/CD Pipeline (Folyamatos Integráció és Szállítás)

A kód élesítése (Deployment) 100%-ban automatizált a GitHub Actions segítségével. Nincs szükség manuális ZIP fájlok feltöltögetésére.

Hogyan működik a folyamat?

A .github/workflows/deploy.yml fájlban definiált robot figyel minden új kódfeltöltést (Push) a main ágon. Ha érzékel egy frissítést, elindít egy Ubuntu Linux futtatókörnyezetet a felhőben, letölti a legfrissebb kódot, majd a GitHub Titkok (Secrets) közé mentett, titkosított hitelesítő adatokkal bejelentkezik a Magyar Hosting (Wepanel) szerverünkre FTP protokollon keresztül, és felülírja a fájlokat.

3. Kódolási Szabványok (Coding Conventions)

A kód tervezésekor elsődleges szempont volt, hogy az algoritmus olvasható, oktatási célokra felhasználható és első féléves egyetemi anyaggal kompatibilis legyen.

  • Nyelvezet: A változók és függvények nevei magyar nyelvűek (pl. szam, alap, jo()). Ennek oka, hogy a beépített kódelemző lejátszóban a magyar diákok számára sokkal átláthatóbb és érthetőbb a működés logikája.
  • Szerkezet: Modern ES6+ funkciók (arrow functions, const/let) szándékos kerülése az alap magban (script.js). Klasszikus var és for ciklusok használata a maximális kompatibilitás és az algoritmikus gondolkodás bemutatása érdekében.
  • Függőségek (Dependencies): A projekt "Vanilla" (tiszta) HTML, CSS és JavaScript, semmilyen külső keretrendszert (pl. React, Angular) nem tartalmaz, minimalizálva az erőforrásigényt.

4. Fejlesztői Környezet (Local Setup)

A projekt lokális fejlesztése rendkívül egyszerű, nem igényel komplex szerver-infrastruktúrát.

  • Előfeltételek: Egy modern kódszerkesztő (pl. Visual Studio Code) és egy böngésző (Safari, Chrome).
  • Futtatás: A fejlesztés során elég a helyi gépen (macOS) megnyitni az index.html fájlt a böngészőben. Nincs szükség Node.js futtatókörnyezet telepítésére vagy localhost szerver indítására.
